# game-ui-asset-studio

## Description and trigger
Use for interface panels, buttons, frames, and HUD assets.

## When to use
Specify states, nine-slice rules, accessibility considerations, and resolution behavior.

## When NOT to use
Do not implement UI logic or localization in an asset brief.

## Conceptual dependencies
Profile, Art DNA, icon studio, and engine adapter.

## Execution
Define state coverage and measurable export constraints.

## Outputs
UI asset manifest and review checklist.

## Limits and care
Keep text and localization outside raster asset metadata when possible.
