# game-asset-validator

## Description and trigger
Use after planning or producing an asset manifest.

## When to use
Check schema, naming, dimensions, budgets, dependencies, license metadata, and provenance.

## When NOT to use
Do not call metadata checks visual proof.

## Conceptual dependencies
Schemas, registry, budget manager, license auditor, and dependency graph.

## Execution
Return explicit checks, failures, and evidence paths.

## Outputs
Machine-readable and human-readable validation results.

## Limits and care
V0.2 has no full visual or runtime renderer.
