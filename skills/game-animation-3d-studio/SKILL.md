# game-animation-3d-studio

## Description and trigger
Use for 3D clip, locomotion, and action animation planning.

## When to use
Define clips, root motion policy, loop behavior, and retargeting requirements.

## When NOT to use
Do not alter runtime controllers while preparing an asset contract.

## Conceptual dependencies
Rigging, 3D model, profile, and runtime validator.

## Execution
Return clip metadata and measurable checks.

## Outputs
3D animation manifest candidate.

## Limits and care
Runtime semantics and authoritative gameplay remain outside this skill.
