# game-vfx-studio

## Description and trigger
Use for 2D visual effects and motion accents.

## When to use
Plan readable effects with duration, blend mode, spawn budget, and fallback behavior.

## When NOT to use
Do not use VFX as a substitute for gameplay feedback design.

## Conceptual dependencies
Art DNA, budget manager, animation studio, and validator.

## Execution
Define effect intent, technical limits, and engine import needs.

## Outputs
VFX brief and manifest candidate.

## Limits and care
Avoid unbounded particles and provider-specific assumptions.
