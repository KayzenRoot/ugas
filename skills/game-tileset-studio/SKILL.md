# game-tileset-studio

## Description and trigger
Use for 2D terrain, modular environment, and tileset planning.

## When to use
Define grid, adjacency, collision metadata, layers, and atlas constraints.

## When NOT to use
Do not make a tileset from unverified references or change map logic.

## Conceptual dependencies
Profile, sprite studio, Art DNA, and engine adapter.

## Execution
Specify tile dimensions, variants, seams, and validation checks.

## Outputs
A tileset plan and asset manifest candidate.

## Limits and care
No final mass production is in the bootstrap scope.
