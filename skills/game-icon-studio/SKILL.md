# game-icon-studio

## Description and trigger
Use for readable inventory, ability, and navigation icons.

## When to use
Define silhouette, small-size readability, variants, and naming.

## When NOT to use
Do not use an icon skill for full-screen illustrations.

## Conceptual dependencies
Art DNA, UI studio, profile, and style auditor.

## Execution
Plan source and target sizes plus contrast checks.

## Outputs
Icon manifest candidate and acceptance criteria.

## Limits and care
No final icon generation is performed by this V0.2 skill.
