# game-3d-model-studio

## Description and trigger
Use for 3D mesh, topology, scale, and export planning.

## When to use
Define target style, polygon budget, units, pivots, and LOD handoff.

## When NOT to use
Do not use for 2D sprites or irreversible remote generation.

## Conceptual dependencies
Profile, Art DNA, material, rigging, LOD, and validator skills.

## Execution
Produce a model brief with technical acceptance checks.

## Outputs
3D asset manifest candidate.

## Limits and care
V0.2 contains contracts, not a mesh generator.
