# game-sprite-studio

## Description and trigger
Use for 2D character, object, or effect sprite planning.

## When to use
Define silhouettes, frames, pivots, resolutions, and export conventions.

## When NOT to use
Do not use for 3D meshes or gameplay logic.

## Conceptual dependencies
Profile, Art DNA, animation, registry, and validator.

## Execution
Return a sprite brief and technical acceptance checks.

## Outputs
Sprite plan or manifest; V0.2 does not mass-generate files.

## Limits and care
Keep engine import settings explicit and profile-scoped.
