# game-style-consistency-auditor

## Description and trigger
Use when reviewing an asset or set against Art DNA and profile rules.

## When to use
Check palette, silhouettes, scale, naming, and declared style constraints.

## When NOT to use
Do not claim pixel-perfect visual proof without a visual comparison artifact.

## Conceptual dependencies
Art DNA, profile, references, and visual regression.

## Execution
Report deterministic metadata checks separately from human visual review.

## Outputs
An actionable consistency report.

## Limits and care
This bootstrap provides contracts and checks, not a computer-vision model.
