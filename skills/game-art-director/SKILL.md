# game-art-director

## Description and trigger
Use when establishing or checking the visual direction of a game asset set.

## When to use
Translate profile goals into composition, mood, palette, and readability guidance.

## When NOT to use
Do not replace a project's approved art direction without an explicit decision.

## Conceptual dependencies
Art DNA, profile, references, and style auditor.

## Execution
State visual intent, constraints, references, and consistency checks before production.

## Outputs
An actionable art direction brief.

## Limits and care
Keep subjective choices labeled as direction, not as objective validation.
